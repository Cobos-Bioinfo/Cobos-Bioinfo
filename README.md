Hi, I'm Alejandro, a bioinformatician based in Barcelona. I studied Genetics (BSc) and Bioinformatics (MSc) at the Universitat Autònoma de Barcelona.

At the CRG I worked with Nextflow and built [Euka-Survey](https://euka-survey.streamlit.app/), a web app that shows how much genomic data exists for any group of eukaryotes. I'm now rebuilding it as a full-stack app with FastAPI, PostgreSQL and React. 

Lately I've been getting into machine learning, and I build small tools on the side, like a daily PubMed digest, a Typst thesis template and a crosshair overlay for games.

Outside of work I enjoy hiking and I'm actively going for FEEC's *100 Cims*.
